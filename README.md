# Remix SSR

Example [Remix](https://remix.run/) app with server-side rendering (SSR). Remix is a full-stack React framework that now continues as React Router in framework mode, which this example uses.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Railpack |
| Project directory | `/` |
| Install command | leave empty |
| Build command | leave empty |
| Start command | leave empty |
| Application port | `3000` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# run in dev mode with watch
npm run dev

# build for production
npm run build

# run the built app
npm run start
```

Requires Node.js 22.22 or later.
